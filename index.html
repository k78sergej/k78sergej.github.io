About

I run a heavily customized Hyprland desktop on Arch, keep a couple of always-on servers for backups and small services, and repurpose old hardware rather than replace it. Most projects here started because I wanted a specific tool that didn't exist yet, so I built it, tested it against my own real setup, and kept using it.

Linux desktop tooling, Android, Python, and self-hosted infrastructure are what I spend most of my time on.

Projects

caelback

→

A stdlib-only Python CLI that snapshots and restores my Hyprland/Caelestia setup, so I can try other dotfiles and always get back to what I had.

python, cli, dotfiles

Hyprform

→

A native GTK4/libadwaita GUI for editing Hyprland configs, both the classic .conf syntax and the newer Lua config API, with real form fields.

gtk4, python, desktop app

LiveWall

→

A wallpaper library manager for Hyprland with tags, favorites, search, and duplicate detection, plus a quick picker on a global keybind.

python, textual, wallpapers

Aurora + echo-dashboard

→

A repurposed Amazon Echo Show turned into a self-hosted bedside display. An Android backend on my phone feeds weather, alarms, and notifications to a kiosk frontend over the LAN, with no cloud involved.

kotlin, android, javascript

echo-dashboard-solo

→

A phone-free fork of the bedside display above, fully standalone with its own journal, habits, reminders, and offline star map. This is the version actually running on my nightstand.

javascript, offline-first, kiosk
